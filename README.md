# Python untuk Pemula

Repositori latihan belajar dasar-dasar Python. Seluruh contoh kode ada di `python-pemula.py`, dan bukti hasil eksekusi tiap bab ada di folder `screenshots/`.

## Materi yang Dipelajari

1. Pengenalan & Instalasi Python
2. Variabel dan Tipe Data
3. Operator
4. Kondisi If Else
5. Perulangan
6. Lists dan Dictionaries
7. Function
8. Class dan Object
9. PIP dan Virtual Environments
10. Konfigurasi Environment/IDE
11. README.md & Requirements.txt

## Cara Menjalankan

1. Buat dan aktifkan virtual environment:

   ```
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   ```

2. Pasang dependensi:

   ```
   pip install -r requirements.txt
   ```

3. Jalankan program:

   ```
   python python-pemula.py
   ```
